## Scope and structure

Seven public pages: `/`, `/features`, `/layers`, `/solutions`, `/pricing`, `/about`, `/contact`.

- The homepage remains at `src/app/page.tsx`. The six new pages use `src/app/(marketing)/layout.tsx`.
- Reusable presentation, navigation, enquiry preparation, metadata and home content live in `src/components/marketing/`.
- All new styles are locally scoped in `marketing.module.css`; brand overrides apply only inside the marketing shell. Manrope/DM Sans and the existing Terrain Layers BrandLockup/assets are reused unchanged.
- `public/marketing/` contains an original SVG spatial study and social sharing artwork. The study is explicitly illustrative, not a real map or product screenshot. No customer data, property location, private export or testimonial is included.
- `src/app/robots.ts` excludes authenticated, API, authentication, account and token-sharing paths from crawling. `sitemap.ts` lists only the seven marketing pages. Vercel previews disallow crawling, have an empty sitemap and use noindex metadata.

The root layout, global CSS, shared BrandLockup, brand masters/assets, manifest, proxy, authentication, protected application, sharing code, application APIs, dependencies, GIS components and Supabase files are unchanged. MaxQI was not modified. Existing URLs are preserved; no redirects are needed.

## Contact and canonical configuration

- Canonical origin reuses `LAND_BANKER_APP_URL`, then `NEXT_PUBLIC_APP_URL`; fallback is `https://landbanker.vercel.app`. Preview hostnames are not used as canonical fallbacks. Configure the owner-approved production domain before rebuilding for a domain change.
- Optional `LANDOS_CONTACT_EMAIL` must be an owner-approved public inbox. It is deliberately absent by default. When configured at build time, the enquiry form prepares a `mailto:` message for the visitor to review and send in their email app. This website sends no email.
- Without that address, the form clearly states there is no listed contact address and downloads `landos-enquiry.txt` for the visitor's records. It never reports a message as delivered. Form entries are not sent to a server.
- No new backend, sending service, subscription service or dependency is introduced.

- Full authenticated production GIS, signup confirmation, real account/session and database E2E workflows were not executed from this independent checkout. They need a suitably configured disposable backend or owner session. Authentication/GIS/share code and shared CSS were not changed; existing pure regression tests and application compilation pass.
- Physical Safari/iPhone/iPad, assistive-technology testing and production performance are not established by desktop Chromium responsive emulation.
- No production deployment, source coverage expansion, new imagery licence, premium layer release or commercial plan release is implied.
- Integration: review this PR, refresh against current `main`, resolve conflicts deliberately, and perform deployment/session checks before a separately authorised merge. This workstream does not merge or deploy production.
