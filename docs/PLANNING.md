# Alpha 3 Property planning

Authenticated `GET /api/properties/:id/planning` authorizes the saved Property in the current Workspace using the user's credential and RLS before querying any external source. It reads enabled same-state catalog entries supported by explicit verified adapters; map-active state does not determine applicability. No privileged client credential, new tenant table, or MaxQI query is introduced.

The unified result is property/layer/feature ID, control type/name/code/value, clipped area and percentage, allowlisted source metadata and retrieval time. Individual source statuses distinguish matched, no exact intersection, no result returned, source unavailable, incomplete/failed request and unsupported jurisdiction; invalid/missing parcel geometry is explicit. No returned result is never interpreted as no restriction.

All Polygon/MultiPolygon parts and holes are submitted as ArcGIS rings with required shell/hole orientation. Turf polygon clipping computes geodesic area in m²; coverage is clipped area / full parcel geometry area. Centroid, envelope and provider Shape_Area are not used to fabricate coverage. Line/point intersections have no percentage. Boundary-only polygon contact can return zero area. Per-feature percentages are not summed across overlapping controls.

Verified query fields cover VIC Zones, All Overlays, Flood overlays, BMO and Heritage; NSW zoning, EPI Heritage and minimum lot size. NSW Heritage has H_NAME/H_ID/SIG and no SYM_CODE, unlike zoning. Unknown fields are not requested. Source features are identified by source layer + OBJECTID; source attributes are allowlisted, not an arbitrary raw payload.

Requests are HTTPS to fixed reviewed endpoints, POSTed geometry (not URLs/logs), with no redirects, up to three concurrent catalog queries, 20-second per-source budgets, 8MB response ceilings and at most 200 returned features per source. Transfer-limit/oversize/invalid responses fail explicitly rather than presenting a partial report as complete. Existing saved geometries are never simplified or overwritten. Large analysis exceeding these ceilings remains unsupported in this release; provider failure leaves the saved workspace usable. Results are computed on demand, not a legal planning certificate or persisted approval record. Automatic provider retries/cache and extensive large-parcel query subdivision are future work.

Live read-only checks 2026-10-07: Ballarat sample returned C1Z at 100%, DDO10 and HO167 at 100%; a boundary-touching TRZ2 returned zero area. Dunoon sample returned RU5 at 100% and a 2,500 m² minimum lot-size control at 100%. NSW Heritage corrected-field query returned no features. External availability can change; fixtures test failure independently.

Tests: full/partial/no intersection, multipart, holes, point/line coverage, empty/malformed/truncated/unavailable source, unsupported state, provenance projection and independent source failure. Local browser regression checks actual API owner-positive/other-workspace-negative/anonymous-negative authorization plus deterministic Inspector rendering, coverage, provenance, failure and retained Property selection across tabs. Rendering fixtures are explicitly not evidence of live government availability.

Property details load on demand, including the complete saved geometry and projected provenance. Fit-bounds and a separate noninteractive highlight persist across inspector tabs. Overview adds Lot/Plan, save date and a planar area-weighted geographic-coordinate centroid (holes subtracted); this centroid may lie outside a concave parcel and never changes Field GPS. Geometry parts do not imply a count of cadastral lots.

`GET /api/properties/:id/relations` separately authorizes the Property, then uses scoped/RLS queries. Field defaults to explicit linked records and offers approximately 500m boundary proximity, including multipart/hole distance, without writing relationships. My Analysis separates explicit property links from exact intersecting indexed candidates and Saved Views containing the property. Lists use bounded 100-candidate pages with explicit next-page controls; empty exact-filter pages can have more candidates. Proximity is a local equirectangular nearby filter, not survey distance. Complete relationship snapshots under concurrent editing are not claimed.
