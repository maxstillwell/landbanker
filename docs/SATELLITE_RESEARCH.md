# Free basemap and satellite source review

Reviewed 27 October 2026 AEDT. This is a source/permission review, not a claim of live provider acceptance. Runtime proxy denied the OWS, imagery, OpenFreeMap public styles and Vercel hosts (HTTP403). No paid API, account, trial or imagery service is used.

## OpenFreeMap styles

The provider-maintained [OpenFreeMap README](https://github.com/hyperknot/openfreemap/blob/main/README.md) confirms free public hosting without API keys, account or request/view caps. Existing provider terms reviewed in MAP_FOUNDATION_REBUILD.md allow commercial use with attribution, with no SLA. The maintained [style README](https://github.com/hyperknot/openfreemap-styles/blob/main/README.md) explicitly documents Liberty, Positron, Bright, Dark and the `/styles/fiord` endpoint. It describes Dark/Fiord as less developed, unmodified upstream styles.

Fiord [provider style JSON](https://github.com/hyperknot/openfreemap-styles/blob/main/styles/fiord/style.json) was retrieved and checked: MapLibre style version 8, 48 layers, OpenMapTiles vector source and low-zoom Natural Earth shaded raster. Neither this raster nor camera pitch is a DEM terrain source. The [upstream licence](https://github.com/openmaptiles/fiord-color-gl-style/blob/master/LICENSE.md) allows redistribution/use under BSD 3-Clause, with design attribution under CC BY 3.0 and visible OpenMapTiles/OSM attribution. LandOS keeps source attribution and adds CARTO/Stamen design credit for Fiord. No MapTiler service/key is used.

Configured style URLs: `https://tiles.openfreemap.org/styles/liberty`, `/styles/positron`, `/styles/bright`, `/styles/dark`, `/styles/fiord`. Provider documentation and source are verified; current live style/sprite/glyph/tile availability remains blocked in this environment. Fiord failure explicitly falls back to Light in the same map. Light is the analysis default; scoped user preferences take precedence. Swatches are illustrative.

There is no Satellite entry pretending to provide verified high-resolution imagery. After network access is available, first request DEA capabilities and select a clearly licensed product; verify actual images at both target locations, dates, CRS, CORS, coverage, attribution and cost-free usage limits. Enable a coverage-bounded raster basemap only after those checks. Otherwise retain the five vector/style basemaps and document the imagery limitation.
