# Draft enquiry: AWS Open Data Terrain Tiles

Suggested recipient: AWS Open Data (`opendata@amazon.com`), with Tilezen maintainers where appropriate. This is a draft; it has not been sent.

Subject: Commercial application access and vertical provenance for Terrain Tiles

Hello,

We are evaluating the AWS Open Data Terrain Tiles dataset (`elevation-tiles-prod`, Terrarium PNG) for an Australian multi-user commercial land-mapping application. Our application would fetch only the map tiles needed for the current view and show the source attributions. We have reviewed the registry entry, Tilezen source attribution and the May 2025 project-member comment that the dataset has no usage limits.

Could you confirm:

1. Whether direct browser requests and caching for a commercial SaaS application are permitted under the current distribution terms, and identify the applicable terms and attribution requirements.
2. Any expected-use, request-rate, bandwidth, cache-control or redistribution restrictions; who bears request and transfer charges; and whether limits can change without notice.
3. The service's best-effort availability, ownership and expected maintenance or discontinuation notice, including whether any service commitment exists.
4. Which vertical reference systems and transformations apply to the Australian SRTM/GMTED/Geoscience Australia mosaic; whether those are consistent within and across tiles; and where per-pixel source, datum, accuracy and no-data information can be obtained.
5. Whether the dataset is appropriate for approximate parcel/profile elevation analysis, and any caveats or limitations we should disclose.

We will keep this provider in development-only testing until these questions and our release checks are resolved. Thank you.
